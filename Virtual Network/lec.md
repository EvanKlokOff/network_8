## виртуализация сетей
![alt text](image-10.png)

Сети тоже можно виртуализировать и производить тонкую настройку сетей

Глобально функционирование сетевого устройство можно разбить на 2 слоя:
* уровень управления (control plane)
  * Принимаются решения о пересылке данных
  * Содержаться механизмы пересылки 2ого и 3его уровня
* уровень передачи данных (data plane)
  * Происходит пересылка трафика через связь двух интерфейсов различных устройств
  * Пересылка происходят уже по готовым настройкам, произведенным на уровне управления

![alt text](image-11.png)

Во время виртуализации существует отдельное выделенное устройство, работающие с уровнем управления - Контроллер

У всех виртуальных сетевых устройств уровень управления удаляется, т.к есть контроллер. Остается только уровень передачи данных

Получается что есть 2 выделенных устройство - контроллер само виртуальное сетевое устройство, на котором осуществляется перессылка трафика

Про таблицы потоков

* Реализованы аппаратно или программно
* Используются для управления потоками через коммутаторы
* Существует 3 типа таблиц
  * Таблица потоков(Flow Table)
    * Сапоставление входящих пакетов с конкретным потоком и определения функций, которые выполняются для пакетов, входящих в этот поток
  * Таблица групп (Group Table)
    * Заполняется из таблицы потоков
    * Выполняются действия влияющие на >= 1 потоков
  * Таблица счетчиков (Meter table)
    * Запускает разные операции, связанные с производительностью(ограничение трафика)
